# Arena Desktop — نسخهٔ ویندوز غیررسمی

یک پوستهٔ دسکتاپ مبتنی بر Electron برای **https://arena.ai**، با رابط کنترلی فارسی و نصب‌کنندهٔ ویندوز. این پروژه وابسته یا مورد تأیید Arena نیست و سرویس، مدل‌ها یا اشتراک جداگانه‌ای ارائه نمی‌کند. شرایط استفادهٔ Arena همچنان برقرار است.

## اصلاح عملکرد در 1.3.1

این نسخه پس از گزارش «نصب انجام می‌شود ولی بقیه کار نمی‌کند» آماده شده است؛ علت دقیق روی سیستم گزارش‌دهنده هنوز با گزارش خطا تأیید نشده. تغییرات، رفع ضعف‌های مشخص برنامه‌اند، نه تضمین کارکرد همهٔ حالت‌های زندهٔ Arena:

- ابزارهای رسمی و نسخه‌ثابت Git/gh همراه برنامه، با بررسی اندازه/SHA-256 پیش از استخراج؛ مسیر ابزارها فقط به فرایندهای خود برنامه افزوده می‌شود، نه PATH عمومی Windows.
- تشخیص کادر پیام در نوار Agent خارج از `main`، ویرایشگر غنی/چندخطی و دکمهٔ تو‌در‌توی ارسال؛ ویرایشگر کد/جستجو/دیالوگ با چت اشتباه نمی‌شود. تبدیل Send به Stop در زمان تولید پاسخ، اتصال را بی‌دلیل باطل نمی‌کند.
- بعد از کلیک، تا مصرف پیش‌نویس یا حالت تولید پاسخ صبر می‌شود؛ کلیکِ بی‌اثر موفق اعلام یا خودکار تکرار نمی‌شود. این تأیید رابط است، نه رسید سمت سرور.
- دانلود مخزن عمومی و پیدا کردن شاخه‌ها بدون ورود اجباری؛ مخزن خصوصی/فهرست حساب/انتشار همچنان نیازمند مجوز حساب شماست.
- استفاده از پراکسی قابل‌تشخیص Windows یا متغیرهای صریح محیطی در عملیات شبکهٔ پنل، بررسی TLS فعال و پیام‌های خطای قابل‌اقدام. پراکسی احرازهویت‌دار یا PAC پیچیده ممکن است تنظیم جداگانه بخواهد.
- دکمهٔ **عیب‌یابی** وضعیت فنی را بدون ارسال پیام/اجرای فرمان نشان می‌دهد؛ **کپی گزارش فنی** فقط با کلیک خودتان انجام می‌شود. گزارش متن چت، فرمان، نام حساب/مخزن، مسیر و اعتبارنامه ندارد و خودکار جایی فرستاده نمی‌شود.

### اگر بعد از نصب هنوز عملی کار نکرد

در همان صفحه‌ای که مشکل دارد **عیب‌یابی ← کپی گزارش فنی** را بزنید و همان گزارش را بفرستید؛ رمز، کد ورود یا توکن نفرستید. کادر پیام باید روی خود سایت باز، یکتا و خالی باشد. پیش‌نویس/پیوست موجود خودکار پاک یا ارسال نمی‌شود. اگر مدل از ابزار ابری خودش استفاده کند یا قرارداد پیام را رعایت نکند، هیچ فرمانی روی Windows اجرا نمی‌شود؛ بعد از ۴۵ ثانیه هشدار آن نمایش داده می‌شود.

## تازه در نسخهٔ 1.3: پروژه‌های GitHub و ادامه با Agent

از دکمهٔ **GitHub** یا `Ctrl+Shift+G` می‌توانید با حساب خودتان از طریق GitHub CLI وارد شوید، مخزن را در پروژهٔ محلی تازه دانلود کنید، پروژهٔ آمادهٔ محلی را پس از پیش‌نمایش در مخزن **خصوصی** جدید منتشر کنید، و مشخصات پروژه/درخواست را به گفتگوی فعلی بفرستید. انتخاب صریح شاخهٔ کاری اختصاصی Agent نیز پشتیبانی می‌شود.

**دریافت خودکار** با یک اجازهٔ جداگانه هر ۳۰ ثانیه، حداکثر یک ساعت، commitهای pushشدهٔ همان شاخه را فقط روی پروژهٔ تمیز و فقط fast-forward دریافت می‌کند. تغییر محلی، واگرایی یا تغییر گفتگو آن را متوقف می‌کند. نه reset/force انجام می‌شود و نه کد دریافتی خودکار اجرا می‌شود. اعتبارنامه‌ها به مدل فرستاده نمی‌شوند.

**در نسخهٔ اصلاحی 1.3.1، Git و GitHub CLI رسمی همراه نصب‌کننده‌اند** و برای این پنل یا فرمان‌های ترمینال AI به نصب جداگانه یا تغییر PATH سیستم نیاز نیست. ابزارها حساب ندارند؛ ورود با حساب خودتان انجام می‌شود. برای اجرای پروژه، پیش‌نیازهای همان پروژه مثل Node.js/Python همچنان لازم‌اند. اتصال محلی gh، اتصال/مجوز مخزن خصوصی در خود Arena را ایجاد نمی‌کند؛ مخزن را در رابط رسمی Agent نیز انتخاب کنید. کار باید توسط Agent روی GitHub **commit و push** شود؛ فایل باقی‌مانده در sandbox ابری یا متن جواب قابل دریافت نیست. برای مسیر دقیق دو سناریو، محدودیت Git LFS/فایل‌ها، خطر تاریخچه و مجوزها، **[راهنمای GitHub](GITHUB.md)** را بخوانید.

## ترمینال AI و حالت خودکار در نسخهٔ 1.2 (آزمایشی)

مدل/Agent در گفتگوی سازگار Arena می‌تواند با قرارداد پیام درخواست PowerShell بدهد. برنامه بدون کپی دستی، فرمان را روی ویندوز شما اجرا می‌کند و خروجی را به همان گفتگو برمی‌گرداند. **دو مجوز اختیاری و مستقل برای هر جلسه** اضافه شده‌اند:

- **اجرای فرمان‌ها بدون تأیید تک‌تک**
- **ارسال خودکار خروجی به Arena و مدل/Agent**

برای چرخهٔ بدون دخالت در مراحل عادی هر دو را روشن کنید و یک‌بار هشدار بومی شروع را بپذیرید. موارد دارای الگوی خطر شناخته‌شده/خروجی مشکوک برای بررسی دستی می‌ایستند. تشخیص ناقص است و امن‌بودن فرمان یا نبود اسرار را تضمین نمی‌کند. **پوشهٔ انتخابی sandbox نیست**؛ فرمان دسترسی واقعی کاربر و شبکه را دارد.

حالت دستی قبلی باقی است؛ اجرای خودکار به‌تنهایی اجازهٔ ارسال خودکار خروجی نیست. مجوزها ذخیره نمی‌شوند و با قطع اتصال، تغییر URL گفتگو، خروج یا پایان حداکثر ۳۰ دقیقه/۲۰ درخواست باطل می‌شوند. در شروع برنامه همیشه خاموش‌اند. پنل از **ترمینال AI** یا `Ctrl+Shift+T` باز می‌شود؛ [راهنمای ضروری و خطرها](TERMINAL.md) را پیش از فعال‌سازی بخوانید.

### دربارهٔ تمام قابلیت‌ها و Agent

این برنامه سایت واقعی را باز می‌کند و قابلیت‌های موجود حساب همچنان از خود سایت می‌آیند؛ اشتراک، محدودیت سمت سرور یا تأییدهای داخلی Arena را تغییر نمی‌دهد. **پل، ابزار رسمی Agent/MCP نیست و مخزن/ترمینال ابری Agent را خودکار به Windows منتقل نمی‌کند.** برای اجرای محلی، مدل/Agent باید همین پروتکل پیام را در صفحه‌ای با کادر ارسال یکتا رعایت کند. حالت دو مدل هم‌زمان پشتیبانی نمی‌شود. قابلیت‌های نیازمند دوربین/میکروفون/ضبط صفحه و بعضی مجوزهای مرورگر نیز در این بسته فعال نیستند؛ جزئیات پایین آمده است.

کاربر کارکرد نسخهٔ 1.1 روی سیستم خود را گزارش کرده است. حالت دستی و حلقهٔ خودکار چندمرحله‌ایِ چت/Agent‌مانند در fixture مصنوعی آزموده می‌شوند؛ PowerShell و بستهٔ واقعی Windows در CI بررسی می‌شوند. سازگاری با سایت زنده، ورود، همهٔ مدل‌ها یا Agent واقعی در این محیط مستقلاً تأیید نشده و «تمام قابلیت‌ها» تضمین نمی‌شود. تغییر ساختار صفحه یا رعایت‌نکردن قرارداد توسط مدل می‌تواند پل را متوقف کند.

## نصب و استفاده

1. فایل `Arena-Desktop-Setup-1.3.1-x64.exe` را در **Windows 10/11، نسخهٔ ۶۴ بیتی x64** اجرا کنید.
2. مسیر نصب را انتخاب کنید؛ نصب به‌صورت پیش‌فرض برای کاربر فعلی و بدون دسترسی Administrator است.
3. برنامه را از میان‌بر **Arena Desktop** باز کنید و در صورت نیاز داخل خود سایت وارد حساب شوید. نشست ورود برنامه با مرورگر شما جداست.
4. اینترنت لازم است؛ هیچ مدل هوش مصنوعی به‌صورت آفلاین یا محلی اجرا نمی‌شود. بستهٔ Electron شامل Chromium است و نصب WebView2 لازم ندارد.

**امضای دیجیتال:** فایل‌های این پروژه گواهی ناشر ندارند؛ Windows/SmartScreen ممکن است هشدار ناشر ناشناخته نشان دهد. هشدارها را بی‌بررسی رد نکنید و آنتی‌ویروس را غیرفعال نکنید. فقط از خروجی مورد اعتماد یا ساخت خودتان استفاده کنید. برای مقایسه با فایل `SHA256SUMS.txt` همراه همان خروجی، در PowerShell اجرا کنید:

```powershell
Get-FileHash .\Arena-Desktop-Setup-1.3.1-x64.exe -Algorithm SHA256
```

هش فقط برابری فایل با خروجی منتشرشده را نشان می‌دهد و جای امضای ناشر یا بررسی امنیتی را نمی‌گیرد.

### امکانات

- پنجرهٔ اختصاصی، میان‌بر دسکتاپ و Start Menu؛ بدون نیاز به تب مرورگر
- بازگشت، جلو، بارگذاری مجدد، صفحهٔ اصلی و بازکردن در مرورگر پیش‌فرض
- حفظ نشست ورود در پروفایل جداگانه و یادآوری اندازهٔ پنجره
- ذخیرهٔ فایل با پنجرهٔ بومی Save As؛ هیچ دانلودی خودکار اجرا نمی‌شود
- صفحهٔ خطای اتصال، تلاش مجدد، پیام انتظار طولانی و رعایت تنظیم کاهش حرکت
- تمام‌صفحه با `F11`، بارگذاری با `Ctrl+R`، تغییر اندازهٔ محتوا با `Ctrl + / -` و بازنشانی با `Ctrl+0`
- منوی **برنامه ← پاک‌کردن داده‌های محلی** برای خروج از حساب Arena و حذف کوکی‌ها، کش و داده‌های محلی سایت (بدون حذف حساب/گفتگوهای سمت سرور یا خروج از حساب مستقل gh سیستم)

### محدودیت ورود و دسترسی‌ها

بارگذاری واقعی سایت و ورود تابع سیاست‌های Arena و ارائه‌دهندهٔ ورود است. بعضی سرویس‌ها ورود داخل Electron را نمی‌پذیرند؛ سازگاری دائمی تضمین نمی‌شود. برنامه CAPTCHA، محدودیت شبکه یا سیاست‌های امنیتی را دور نمی‌زند و User-Agent را برای فریب سرویس ورود تغییر نمی‌دهد. در چنین حالتی از **بازکردن در مرورگر** استفاده کنید؛ ورود در مرورگر، نشست را به برنامه منتقل نمی‌کند.

دوربین، میکروفون، موقعیت مکانی، اعلان‌ها، ضبط صفحه و دستگاه‌های USB/HID/Serial مجوز ندارند. در نتیجه قابلیت‌هایی که به این دسترسی‌ها نیاز دارند کار نمی‌کنند. انتخاب و بارگذاری فایل با فایل‌پیکر معمول سایت انجام می‌شود. فقط نوشتن استاندارد کلیپ‌بورد و تمام‌صفحه برای صفحهٔ اصلی سایت مجاز است. لینک‌های خارجی امن پس از تأیید شما در مرورگر باز می‌شوند؛ طرح‌های `file:`, `javascript:`, `data:` و اجرای برنامه‌های خارجی مسدودند.

## ساخت از سورس

پیش‌نیاز: Node.js **22.12 یا جدیدتر** و npm. پروژه مستقل از وب‌سایت ATLAS در ریشهٔ مخزن است.

```bash
cd desktop
npm ci
npm run check
npm test
npm start          # اجرای توسعه روی سیستم دارای محیط گرافیکی
npm run dist:win   # ساخت نصب‌کنندهٔ x64 در dist/
```

ساخت Windows از Linux نیز بدون Wine ممکن است: ویرایش آیکون و مشخصات PE با `resedit` انجام می‌شود. برای ساخت صرفاً نیازی به دانلود Electron مخصوص سیستم میزبان نیست:

```bash
# Linux/macOS؛ فقط برای مرحلهٔ نصب وابستگی‌های ابزار ساخت
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci
npm run dist:win
```

برای اجرای `npm start` بعد از نصب با گزینهٔ بالا، ابتدا `node node_modules/electron/install.js` را بدون آن متغیر محیطی اجرا کنید. ساخت به دسترسی npm و دارایی‌های انتشار GitHub برای Electron، NSIS و دو ابزار رسمی نیاز دارد. `npm run tools:prepare` بایگانی‌های پین‌شده را فقط در پوشهٔ نادیده‌گرفته‌شدهٔ `build/` دانلود/اعتبارسنجی می‌کند؛ حساب یا ابزار نصب‌شدهٔ ماشین سازنده کپی نمی‌شود. در اجرای توسعه، بدون آماده‌سازی/مسیر resources، Git/gh نصب‌شده استفاده می‌شوند. مجوزها و نشانی سورس ابزارها در [THIRD-PARTY.md](THIRD-PARTY.md) آمده‌اند.

### ساخت روی GitHub Actions

فایل `.github/workflows/arena-desktop-windows.yml` روی Windows خروجی را می‌سازد، آزمون‌ها و بررسی ساختار PE/ASAR و fuseها را اجرا می‌کند و اجرای Git/gh بسته‌بندی‌شده، helper با توکن جعلی آفلاین، ابزارها داخل PowerShell بدون PATH نصب‌شده و ارسال تک‌پیام چندخطی در کادر ساده/غنی واقعی Chromium روی صفحهٔ مصنوعی را بررسی می‌کند. بررسی خواندنی HTTPS عمومی GitHub بدون credential helper نیز جداگانه انجام می‌شود. ورود انسانی OAuth و DOM زندهٔ Arena با این تست‌ها ثابت نمی‌شوند. راه‌اندازی آفلاین برنامه هم بررسی می‌شود؛ نصب‌کننده، `SHA256SUMS.txt` و راهنماهای فارسی را به‌صورت artifact نگه می‌دارد. پس از فرستادن تغییرات به GitHub، workflow با تغییر فایل‌های دسکتاپ اجرا می‌شود؛ اجرای دستی از بخش Actions نیز ممکن است. هیچ release یا به‌روزرسانی خودکاری منتشر نمی‌شود.

### مرزبندی امنیتی

- سایت در `WebContentsView` مجزا با `sandbox: true`, `contextIsolation: true`, `nodeIntegration: false`, `webSecurity: true` اجرا می‌شود. محتوای راه‌دور preload یا پل Node.js ندارد.
- فقط پوستهٔ محلی با CSP محدود اعمال مشخص نوارابزار، مدیریت جلسهٔ ترمینال و عملیات محدود پروژهٔ GitHub را از IPC فراخوانی می‌کند. IPC ترمینال علاوه بر فرستنده و فریم اصلی، URL دقیق فایل محلی پوسته را بررسی می‌کند؛ API عمومی `exec`/`spawn` وجود ندارد. فرمان از snapshot ثابت درخواست فعال با تأیید همان فرمان یا مجوز صریح اجرای خودکارِ جلسه اجرا می‌شود. مجوز مستقل ارسال، مهلت، URL و epoch در main بررسی می‌شوند؛ پرچم تغییر مجوز از مدل پذیرفته نمی‌شود. الگوهای هشدار امنیت فرمان را تضمین نمی‌کنند.
- ناوبری داخل برنامه به دامنه‌های دقیق Arena/نسخهٔ قدیمی LMArena و مسیرهای مشخص Google/Apple/GitHub برای ورود محدود است. زیردامنه‌های فریبنده و URLهای دارای نام کاربری/رمز معتبر محسوب نمی‌شوند.
- TLS و web security غیرفعال نمی‌شوند. کوکی‌ها با قابلیت رمزنگاری Electron مدیریت می‌شوند؛ برنامه کدی برای جمع‌آوری رمز عبور، کلید API یا ارسال تله‌متری اضافه ندارد. خود سایت همچنان داده‌ها را مطابق سیاست‌های خودش پردازش می‌کند.
- fuseهای `RunAsNode`, `NODE_OPTIONS` و آرگومان‌های Node inspector غیرفعال‌اند؛ بارگذاری از ASAR و بررسی یکپارچگی آن فعال است. این‌ها جایگزین امضای دیجیتال نیستند.

پروفایل در `%APPDATA%\ArenaDesktopUnofficial` ذخیره می‌شود. حذف برنامه برای حفظ نشست در نصب مجدد، این پوشه را حذف نمی‌کند؛ برای حذف کامل، قبل از حذف برنامه داده‌های محلی را از منو پاک کنید یا پس از بستن برنامه این پوشه را حذف کنید. به‌روزرسانی خودکار وجود ندارد؛ برای اصلاحات امنیتی Electron، وابستگی‌ها و فایل نصب باید مجدداً ساخته و جایگزین شوند.
