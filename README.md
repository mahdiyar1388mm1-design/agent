# ATLAS — معماری سازمانی هلدینگ هوش مصنوعی

یک وب‌سایت تک‌صفحه‌ای (React + Vite، راست‌به‌چپ) که ساختار ریشه‌ای یک هلدینگ هوش مصنوعی را
به‌صورت کامل نشان می‌دهد: از هیئت‌مدیره و دپارتمان‌های ستادی تا سه شرکت عملیاتی
(Trading / Development / Marketing)، کارخانه ساخت Agent، ستاد همکاری بین‌شرکتی،
خزانه مرکزی و زیرساخت مشترک.

## اجرا

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # خروجی در dist/
```

## ساختار

```
src/
  data/
    board.ts        # حاکمیت، دپارتمان‌های ستادی هلدینگ، کارخانه Agent
    companies.ts    # سه شرکت: Trading, Development, Marketing
    systems.ts      # همکاری بین‌شرکتی، خزانه/کیف پول، زیرساخت مرکزی
    org.ts          # مدل داده مشترک، شاخص‌ها و درخت سازمان
  components/       # نقشه ریشه، درخت سازمانی، جستجو، پروفایل Agent، آناتومی درخت
  pages/            # نمای کلی، نقشه، ساختار، شرکت‌ها، فهرست، عملیات، زیرساخت، نقشه راه
```

## صفحات

| مسیر | محتوا |
| --- | --- |
| `#/` | نمای کلی + آناتومی ریشه‌ای (ریشه/تنه/شاخه/برگ) + سه شرکت + قابلیت‌های خودگردان + خزانه |
| `#/map` | نقشه شعاعی تعاملی کل هلدینگ و بزرگ‌نمایی هر شاخه |
| `#/structure` | درخت کامل سازمان با مسیر `?b=<branch>&s=<section>&a=<agent>` |
| `#/companies` | جزئیات سه شرکت، تیم رهبری و دپارتمان‌ها |
| `#/directory` | جستجو/فیلتر ۴۷۶ نقش + خروجی CSV |
| `#/operations` | همکاری سه شرکت، اقتصاد داخلی و خزانه امن |
| `#/infrastructure` | پانزده سامانه مرکزی و دروازه‌های کنترل |
| `#/roadmap` | ترتیب راه‌اندازی، سلسله‌مراتب، اصول و ریسک‌ها |

میان‌بر جستجو: `Ctrl/⌘ + K`.

## نکته

شاخص‌ها، وضعیت‌ها، سطح خودگردانی و ابزارها داده نمونه برای نمایش معماری هستند و به
سیستم عملیاتی واقعی متصل نیستند. کلید خصوصی کیف پول در هیچ سطحی به Agent داده نمی‌شود.
