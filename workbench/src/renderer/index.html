قدرت مدل‌ها، با کلید خودت.

          

            کلید به متن گفتگو، Arena و محیط افزونه تزریق نمی‌شود. نگهداری
            رمز‌شده اختیاری است. کد افزونه با دسترسی کاربر اجرا می‌شود؛ فقط
            افزونهٔ مورداعتماد نصب کن.
          

          inference.dahl.global / v1
        

        
        

        
        

          جابه‌جایی خودکار فقط پس از اعلام صریح پایان سهمیهٔ کلید. خطای عمومی
          429 یا رد مجوز، باعث تعویض کلید نمی‌شود. بازنشانی، درخواست زندهٔ بررسی
          سهمیه نمی‌فرستد؛ در درخواست بعد دوباره امتحان می‌شود.
        

        

          کلیدی که قبلاً در چت فرستاده‌ای را در سرویس تعویض کن؛ ابطال آن از داخل
          این برنامه انجام نمی‌شود.
        

      

      

        

          
          
Arena، پشت یک ابزار واقعی.

          

            Chrome با پروفایل مستقل عامل باز می‌شود. خودت وارد شو، حالت Agent یا
            گفتگوی تک‌مدلی و مخزن مجاز را انتخاب کن. مرورگر و کوکی‌های شخصی کپی
            نمی‌شوند.
          

        

        
        

        

          رمز، MFA و CAPTCHA با توست. عامل می‌تواند درخواست را از کادر
          قابل‌شناسایی Arena بفرستد و پاسخ قابل‌شناسایی را بخواند. تغییر ساختار
          سایت یا محدودیت حساب می‌تواند این مسیر را متوقف کند؛ اتصال زندهٔ همهٔ
          حالت‌ها تضمین نشده است.
        

        

          ترمینال و مخزن ابری Arena با سیستم محلی یکی نیست. مجوز مخزن در Arena
          جدا از ورود GitHub محلی است.
        

      

      

        

          
          
از مخزن تا ادامهٔ کار.

          

            Git و gh رسمی همراه EXE هستند. با حساب خودت وارد شو؛ عامل می‌تواند
            مخزن را دریافت، وضعیت را بررسی و تغییرات را با تأیید تو منتشر کند.
          

        

        

          
        

        

          
        

        

        

        

          دریافت عمومی بدون ورود هم ممکن است. انتشار پیش‌نمایش و تأیید بومی
          می‌خواهد. مخزن تازه خصوصی است؛ force-push، reset، merge خودکار PR یا
          Release نداریم.
        

      

      

        

          
          
روش کارِ مخصوص خودت.

          

            Skill، راهنمای متنی Markdown/JSON است. Plugin، سرور استاندارد MCP
            stdio محلی است. نصب با تأیید تو انجام می‌شود؛ فروشگاه یا دانلود
            پنهان نرم‌افزار نداریم.
          

        

        
        

        

          قالب manifest افزونهٔ MCP
          
{
  "kind": "mcp",
  "name": "My trusted plugin",
  "command": "C:\\path\\to\\server.exe",
  "args": []
}

        

        

          افزونه sandbox نیست و با دسترسی واقعی کاربر کار می‌کند. Node/Python/uv
          و پیش‌نیازهای موردنیازش باید نصب باشند. اطلاعات ورود و env secrets
          داخل manifest نگذار. Skill و توضیح ابزار نمی‌توانند مجوزها را گسترش
          بدهند.
        

      

      

        

          
          
این اتاق فرمان چطور کار می‌کند؟

            استفاده کنند. برنامه نتیجهٔ واقعی ابزار را ثبت می‌کند. یک تیم ترتیبی
            داریم، نه عامل‌های نامحدود یا کنترل بی‌اجازهٔ کل سیستم.
