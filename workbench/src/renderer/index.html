DAHL INFERENCE

کلیدها، فقط پیش خودت

کلیدها به مدل، Arena، افزونه یا گزارش فعالیت داده نمی‌شوند. اگر کلیدی را در چت فرستاده‌ای، آن را عوض کن و کلید تازه را اینجا وارد کن.

inference.dahl.global / v1

جابه‌جایی فقط وقتی سرویس صریحاً پایان سهمیهٔ کلید را اعلام کند. خطای عمومی 429 باعث تعویض کلید یا دورزدن محدودیت سرعت نمی‌شود.
MANAGED CHROME

Arena، یک ابزار برای عامل

ورود را یک‌بار در Chrome جداگانهٔ عامل انجام بده و گفتگوی تک‌مدلی یا Agent و مخزن مجاز را انتخاب کن. پروفایل شخصی Chrome تو خوانده یا کپی نمی‌شود.

بعد به Orbit برگرد و کار را بسپار. عامل برای کار، همان پروفایل را در پس‌زمینه باز می‌کند. رمز، MFA و CAPTCHA با خودت است. تغییر ساختار Arena می‌تواند اتوماسیون را متوقف کند؛ اتصال رسمی مخزن داخل Arena جداست.
GITHUB CONNECTION

مخزن واقعی. کار واقعی.

Git و gh همراه برنامه‌اند؛ هیچ حساب یا اعتبارنامهٔ سازنده‌ای همراه آن نیست. ورود GitHub محلی و ورود مخزن در Arena دو اتصال جدا هستند.

دانلود عمومی بدون ورود هم ممکن است. انتشار با پیش‌نمایش و اجازهٔ بومی انجام می‌شود؛ مخزن جدید خصوصی است. reset، force-push و merge خودکار نداریم.

 
EXTEND YOUR AGENT
روش کار خودت را اضافه کن
Skill راهنمای متنی Markdown یا JSON است. Plugin یک سرور MCP استاندارد stdio با manifest محلی است؛ نصب برنامه‌نویسی‌شده با دسترسی واقعی سیستم، فقط از منبع مورداعتماد.
قالب manifest افزونه
{
  "kind": "mcp",
  "name": "My trusted plugin",
  "command": "C:\\path\\to\\server.exe",
  "args": []
}
افزونه sandbox نیست؛ Node/Python/uv و پیش‌نیازهای آن، اگر لازم باشند، باید نصب باشند. نام ابزار و Skill هرگز مجوزها را گسترش نمی‌دهد.
