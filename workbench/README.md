# Orbit Agent — عامل مستقل Windows (نسخهٔ اولیهٔ 0.1)

**تو در EXE به عامل دستور می‌دهی؛ عامل با مدل‌های Dahl برنامه‌ریزی می‌کند، می‌تواند به Arena در مرورگر جداگانه درخواست بدهد و پاسخ قابل‌مشاهده را بخواند، و با فایل‌ها، PowerShell، GitHub و افزونه‌ها ادامه دهد.** این پروژه نمایش صرفِ سایت Arena یا برنامهٔ رسمی Arena/Dahl نیست. ATLAS و نسخهٔ قبلی Arena Desktop جدا و حفظ شده‌اند.

## قابلیت‌های واقعی این نسخه

- رابط مستقل گفتگو/اجرای کار، پروژهٔ محلی، تیم سه‌مدلی، فعالیت مدل‌ها/ابزارها، توقف و امکان ادامهٔ کارِ فعال در پس‌زمینه با آیکون کنار ساعت.
- اتصال JSON سازگار با Chat Completions به `https://inference.dahl.global/v1/chat/completions`. نمونهٔ curl کاربر اجرا/ذخیره نمی‌شود. مدل‌ها دقیقاً `zai-org/GLM-5.3-Flash`، `deepseek-ai/DeepSeek-V4-Flash-0731` و `MiniMaxAI/MiniMax-M2.7` هستند. وجود مدل/مجوز حساب فقط با پاسخ زندهٔ سرویس مشخص می‌شود؛ در این محیط دسترسی مستقیم به آن سرویس نداریم.
- حالت تیم: GLM برنامه‌ریزی، DeepSeek ادامهٔ اجرای ابزار و MiniMax بازبینی شواهد. حالت تک‌مدلی نیز هست. سازگاری function calling برای سرویس هنوز زنده آزمایش نشده؛ اگر صریحاً tools پشتیبانی نشود، قرارداد JSON سخت‌گیرانه استفاده می‌شود؛ متن آزاد به فرمان حدس‌زده تبدیل نمی‌شود.
- کلیدها فقط در حافظه یا، با انتخاب کاربر، رمز‌شده با حفاظت حساب Windows ذخیره می‌شوند. هیچ کلید کاربر/سازنده در سورس، EXE، Git، تاریخچه، پاسخ وضعیت یا محیط افزونه قرار نمی‌گیرد. کلید فرستاده‌شده در چت را عوض کنید و تازه را فقط در تنظیمات EXE وارد کنید. برنامه امکان ابطال کلید در سرویس را ندارد.
- گردش کلید فقط پس از پاسخ صریح پایان سهمیهٔ همان کلید؛ همه که تمام شوند کار متوقف می‌شود. HTTP 401/403، خطای شبکه و 429 عمومی سبب جابه‌جایی برای دورزدن محدودیت نمی‌شوند؛ زمان Retry-After نمایش داده می‌شود. محدودیت سرویس باید رعایت شود.
- خواندن/نوشتن UTF-8 در پروژهٔ انتخابی، بدون ابزار حذف؛ مسیر traversal، پیوند، `.git` و نام‌های معمول اعتبارنامه/`.env` رد می‌شوند. هر فایل حداکثر ۲۵۶ KiB. دسترسی مستقیم فایل فقط داخل پروژه است؛ **PowerShell و افزونه sandbox نیستند** و می‌توانند با دسترسی واقعی کاربر از آن خارج شوند.
- PowerShell واقعی Windows در پوشهٔ انتخابی، هر فرمان حداکثر ۱۲۰ ثانیه/۱۲۸ KiB، بدون profile یا ExecutionPolicy bypass. Git و gh رسمی همراه برنامه‌اند. Node.js/Python/npm یا پیش‌نیاز پروژه/افزونه جداگانه لازم‌اند. سرویس دائمی/مدیریت dev-server در این نسخه ارائه نمی‌شود.
- مرورگر واقعی Chrome با پروفایل **جداگانهٔ Agent**؛ مرورگر/کوکی‌های شخصی کپی یا متصل نمی‌شوند. Chrome نصب‌شده لازم است؛ دانلود خاموش مرورگر نداریم. عامل وب عمومی HTTPS را می‌خواند، کلیک و متن معمولی را وارد می‌کند. شبکهٔ خصوصی، localhost، فایل، دریافت دانلود و WebSocket مسدودند. برای دامنهٔ تازه مجوز بومی می‌گیرد؛ رمز، MFA و پرداخت با کاربر است.
- ابزار `arena_ask` با کادر خالی یکتا درخواست می‌فرستد و منتظر پاسخِ قابل‌شناسایی همان سایت می‌شود؛ کلیک بی‌اثر دوباره تکرار نمی‌شود. ورود، انتخاب حالت Agent/مدل و مجوز/انتخاب مخزن خصوصی در Arena را **خودت** انجام می‌دهی. ابزار/ترمینال ابری Arena به سیستم محلی منتقل نمی‌شود. اگر DOM عوض شود، پاسخ قابل‌شناسایی نباشد، CAPTCHA یا محدودیت سرویس باشد، خطا/مکث می‌دهد؛ دورزدن یا موفقیت ساختگی نداریم. سازگاری زنده با Arena/حساب تو تضمین نشده است.
- GitHub: ورود رسمی gh با کد دستگاه، فهرست مخزن‌ها، clone در زیرپوشهٔ تازه، وضعیت و دریافت تمیز fast-forward، انتشار با پیش‌نمایش/تأیید بومی. مخزن جدید خصوصی، origin/شاخهٔ موجود حفظ؛ بدون reset/stash/force-push، merge PR یا Release. تاریخچهٔ reachable نیز هنگام انتشار ارسال می‌شود؛ بررسی فایل فعلی همهٔ اسرار تاریخچه را تشخیص نمی‌دهد. حفاظت‌ها و محدودیت Git LFS/فیلتر/اندازهٔ کنترل‌کنندهٔ [`desktop/GITHUB.md`](../desktop/GITHUB.md) برقرارند.
- Skill به‌شکل Markdown یا JSON متنی، و Plugin استاندارد **MCP stdio** با manifest محلی و تأیید نصب. فایل اجرایی یا Node/Python/uv موردنیاز باید در سیستم موجود باشد؛ برنامه فروشگاه افزونه/نصب خاموش نرم‌افزار ندارد. متن Skill و توضیح ابزار، مجوز نیستند. اجرای MCP واقعاً با دسترسی کاربر است و فقط باید کد مورداعتماد نصب شود.

## شروع روی Windows 10/11 x64

1. EXE معتبر `Orbit-Agent-Setup-0.1.0-x64.exe` را نصب کن. نسخهٔ اولیه و **بدون امضای ناشر** است؛ Administrator لازم نیست.
2. تنظیمات امن ← کلیدهای تازهٔ Dahl، هر کدام یک خط. برنامه کلیدها را پس از ثبت نشان نمی‌دهد. حافظه پیش‌فرض است؛ گزینهٔ نگهداری رمز‌شده اختیاری است.
3. برای کار محلی، **انتخاب پروژه** را بزن. برای استفاده از Arena، **Arena & Chrome ← بازکردن Chrome و ورود** را بزن، خودت وارد شو و گفتگو/Agent و مخزن مجاز را انتخاب کن. سپس به Orbit برگرد؛ هنگام کار Chrome با همان پروفایل در پس‌زمینه باز می‌شود. اگر صفحهٔ ورود/انتخاب پروژه است یا پیش‌نویس دارد، خودکار پاک نمی‌شود.
4. GitHub ← ورود در مرورگر، برای مخزن خصوصی/انتشار. حساب gh خودت به کار می‌رود؛ اتصال رسمی داخل Arena مستقل است.
5. حالت **اجرای کار**، مدل/تیم و درخواست دقیق را انتخاب کن. یک مجوز بومی برای همین کار و ارسال دادهٔ لازم به سرویس‌ها می‌گیری. پوشه، داده و افزونه باید مورداعتماد باشند. برای صرف گفتگو، حالت **گفتگو** هیچ ابزار اجرایی را مجاز نمی‌کند.
6. فعالیت‌ها، فرمان‌ها و نتیجه‌ها را در پنل پشت صحنه ببین. کار حساس ممکن است تأیید جداگانه بگیرد؛ تشخیص خطر/اسرار ناقص است. سقف ۳۰ دقیقه/۲۰ ابزار. توقف ادامهٔ مراحل/مجوزها را باطل و برای بستن ابزارهای متعلق به کار تلاش می‌کند؛ تغییر فایل، پیام، commit یا ارسال انجام‌شده rollback نمی‌شود. فرایند جداشده ممکن است بماند؛ Task Manager را بررسی کن.
7. بستن پنجرهٔ کارِ فعال سه انتخاب دارد: ادامه در پس‌زمینه، توقف/خروج، لغو. ادامه فقط در همین اجرای برنامه است؛ بعد از restart کاری خودکار از سر گرفته نمی‌شود. ادامهٔ گفتگو با حفظ متن و شواهدِ محدودشدهٔ قبلی ممکن است؛ هر پیام اجرایی مجوز تازه می‌گیرد. کار جدید گفتگوی جدا می‌سازد؛ فهرست کنار صفحه گفتگوهای همین اجرا و همان پوشه را باز می‌کند. پیام‌ها/فعالیت‌ها/گفتگوها فعلاً فقط در حافظه‌اند، نه تاریخچهٔ دائمی.

## افزودن Skill / Plugin

یک فایل `.md` شامل دستور کار متنی، یا JSON زیر را از **منبع مورداعتماد** انتخاب کن. نصب هیچ دسترسی جدیدی خارج از مجوز همین کار به Skill نمی‌دهد:

```json
{ "kind": "skill", "name": "Test first", "instructions": "Inspect the project and run its existing tests before changing behavior." }
```

MCP stdio (هیچ token/env/رمزی داخل manifest نگذار):

```json
{ "kind": "mcp", "name": "My trusted server", "command": "C:\\path\\to\\server.exe", "args": [] }
```

اجرای فرمان‌های manifest می‌تواند نرم‌افزار را دانلود/اجرا کند؛ اجازهٔ نصب و سپس مجوز همین کار صریح‌اند. پشتیبانی از MCP به‌معنی sandbox یا امن‌بودن افزونه نیست. فقط stdio محلی در این نسخه است، نه سرور HTTP یا فروشگاه افزونه. کلید Dahl به محیط افزونه تزریق نمی‌شود؛ کد مورداعتمادِ هم‌سطح کاربر از نظر OS می‌تواند به فایل‌های همان کاربر دسترسی داشته باشد.

## آزمون و مرزبندی

تست‌های واحدِ خزانه، سهمیه/گردش کلید، عدم دورزدن 429/403، قرارداد ابزار، لغو/مهلت، فایل/پیوند، ورودی وب، Skill و UI اجرا می‌شوند. Windows CI خود EXE بسته‌بندی‌شده را با PowerShell و فایل واقعی، Git/gh همراه و helper با توکن **جعلی آفلاین**، Chrome واقعی و **صفحهٔ مصنوعی Arena** و واردکردن SDK افزونه بررسی می‌کند؛ HTTPS خواندنی metadata مخزن عمومی هم جداگانه آزموده می‌شود. این‌ها **آزمون زندهٔ Dahl، OAuth انسانی، Arena فعلی یا یک افزونهٔ ثالث نصب‌شده نیستند**. هیچ موفقیت زنده‌ای از این fixtureها نتیجه نمی‌شود.

Electron محلی sandbox/context-isolated و بدون Node در renderer است؛ API عمومی exec، دریافت کلید یا IPC به صفحهٔ وب وجود ندارد. کلیدها فقط در main برای Authorization به endpoint ثابت HTTPS Dahl استفاده می‌شوند. مرورگر سایت‌ها فرایند Chrome جداست. TLS/امنیت مرورگر خاموش نمی‌شود. کد/فرمان، وب‌سایت، Skill و خروجی ابزار غیرقابل اعتمادند؛ مجوز خودکار یعنی پذیرفتن خطر واقعی. این برنامه sandbox، DLP کامل، تضمین rollback یا تضمین سازگاری همهٔ سایت‌ها نیست.

## توسعه و ساخت

```bash
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm --prefix desktop ci
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm --prefix workbench ci
npm --prefix workbench run check
npm --prefix workbench test
npm --prefix workbench run dist:win
```

برای اجرای توسعهٔ Electron گرافیکی بعد از نصب بدون دانلود، ابتدا نصب باینری Electron را در `workbench` طبق ابزار رسمی Electron تکمیل کنید. منابع Git/gh فقط از ZIP عمومیِ نسخه‌ثابت با اندازه و SHA-256 پین‌شده آماده می‌شوند؛ تنظیم/اعتبارنامهٔ ماشین سازنده کپی نمی‌شود. مجوزها و سورس آن‌ها در THIRD-PARTY همراه EXE است. Workflow مستقل `Orbit Agent / Windows` فقط artifact می‌سازد، نه Release/آپدیت خودکار.
